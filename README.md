# fm-1-impressionism

A generative ambient firmware for the [M-VAVE FM-1](https://www.m-vave.com/product?id=fm-1) pocket synthesizer.

It's built to drift, not to be played: voices free-run on their own slow, semi-random timers inside the harmonic world of Debussy/Ravel-era Impressionism — whole-tone and pentatonic scales, extended and quartal chords, parallel "planing" motion over a sustained pedal tone — rather than a clocked sequencer or a conventional keyboard voice.

See [CLAUDE.md](./CLAUDE.md) for the full mission, firmware architecture, toolchain, and distribution notes.
